# Aspirochlorine focal-locus evidence

This editable evidence view covers the author-approved Atlas rank 1 record for *Aspergillus novoparasiticus* CBS 126849. The stable target locator is GCA_009176405.1 / ML733399.1:241–173,302. The SVG keeps the FunBGCeX boundary above the antiSMASH boundary, includes the complete MIBiG BGC0001123.5 reference region, and is backed by the TSV files in this directory.

The aspirochlorine name, MIBiG match, FunBGCeX match, scores, protein alignments, and synteny are component evidence. They do not establish metabolite production or biological ground truth. The antiSMASH score of 81 and FunBGCeX score of 95.8 are not protein identity; the directly retained focal-core alignment is 0.93 identity and 0.95 similarity.

Files: `focal_locus.tsv` contains the bounded record; `records.tsv` defines the 12 displayed records; `genes.tsv` contains 380 CDS rows; `funbgcex_genes.tsv` contains the 38 FunBGCeX genes; `alignments.tsv` contains 1,270 protein alignments; and `focal_locus_aspirochlorine_gene_context.svg` is the editable figure.
