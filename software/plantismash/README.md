# Pinned plantiSMASH source recipe

This directory builds the supplied-CDS plant runtime on Linux amd64 from public
upstream inputs. It retains strict native completion, original sequence/CDS
identity checks, record mappings and HMM-search accounting.
It does not predict missing plant annotations.

The usual repository command is `bin/prepare_plantismash.py`; see
[`docs/PLANTISMASH_RUNTIME.md`](../../docs/PLANTISMASH_RUNTIME.md). The underlying
steps, also usable from the corresponding-source archive, are:

```bash
python3 prepare.py --cache /path/to/source-cache --context /path/to/new-context
# Pull the exact base_image value in sources.lock.json if it is not local.
DOCKER_BUILDKIT=0 docker build --pull=false --network none \
  --cpu-quota 200000 --memory 8g \
  -t plantismash:prepared /path/to/new-context
python3 package_sif.py --image plantismash:prepared \
  --worker-image YOUR_COMPLETE_CLUSTERWEAVE_WORKER_IMAGE \
  --output /path/to/new-software/plantismash/plant.sif \
  --expected-sha256 PREFERRED_SIF_SHA256_FROM_RUNTIME_LOCK \
  --max-export-bytes 8589934592 --min-free-bytes 32212254720 \
  --tmpfs-build-gib 12
```

The builder image must contain the supported official non-setuid Apptainer
1.5.5 package. The Docker daemon is used only by the operator for image build,
export and the bounded packaging container; its socket is never mounted into
that container. Packaging has no network, uses UID/GID 65534, drops all
capabilities, and writes only its temporary work directory. Failed attempts are
retained; a checksum mismatch is not promoted.

`sources.lock.json` pins executable and Python dependencies.
`resources.lock.json` pins the search databases, Pfam 27, ConnecTF, TAIR,
subgroup, smCOG and Active Site Finder resources. Acquisition verifies both
archive and extracted identities; the offline build generates indexes and runs
native prerequisites plus a headless TreeGraph rendering check. No job acquires
these assets. The renderer uses fonts from the pinned Matplotlib wheel.

`SOURCE_DATE_EPOCH=315532800`, fixed source-archive metadata and the verified
HMM index layout constrain packaging. The accepted identity is the exact
`runtime.lock.json` pin; a candidate or a passing fixture is not an accepted
scientific runtime. A differing build is retained for diagnosis, never promoted.
The SSI filename padding retains the required HMM index layout without changing
model bytes or thresholds.

The operator helper preserves a minimum 30 GiB disk reserve and prospectively budgets
36 GiB for acquisition, staging, installed layers and temporary copy layers.
The operator helper retires only its own unreferenced temporary build stage,
with metadata and history receipts; final runtime images and failure evidence
remain. Packaging separately checks an 8 GiB export bound and uses a 12 GiB
bounded temporary filesystem (20 GiB container memory). Check fresh disk and
memory headroom before every attempt.

`modifications.json` binds ten original and modified files. Changes include
Python 3 compatibility, checked external-tool failures, headless smCOG rendering,
Newick label quoting, restoration of the full-Pfam execution path, and mapping
Pfam/ASF positions through supplied spliced CDSs, and subgroup handling of
valid single-item detection annotations. The complete
modified plantiSMASH source and build files are available in the hosted source
archive generated by `source_offer.py`. See `LICENSE.txt` and the upstream
package notices. `sources.lock.json` records dependency identities and declared
licenses. This recipe does not publish or license a prebuilt aggregate runtime.
